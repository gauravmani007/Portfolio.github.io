# Gaurav Mani - Portfolio Website

Personal portfolio of a B.Tech CSE (AI) student, showcasing AI/ML and full-stack projects.

**Live demo:** https://gauravmani007.github.io/Portfolio.github.io/

## Features
- Typing hero animation, About, Skills (animated bars), Projects, Achievements, Contact
- Project filters (All / AI / Full Stack / Web) and a details popup
- Contact form powered by Web3Forms
- Responsive, dark theme with green accent

## Projects
- Face Recognition System for Lost Persons (Python, Streamlit, MediaPipe, SQLite, OpenCV)
- Search Chatbot (React, Node.js, Express, Google Gemini API)
- Personal Portfolio (HTML, CSS, JavaScript, Bootstrap)
- AI Interview Prep Platform (React, Node.js, MongoDB, GenAI)
- Civic Reporting Platform (React, Node.js, MongoDB, Google Maps API, AI/ML)
- Find Recipe and Wings Music (HTML, CSS, JavaScript)

## Adding a skill or project
Edit the `SKILLS`, `PROJECTS` or `ACHIEVEMENTS` arrays at the top of `dynamic.js`. The page rebuilds itself.

## Structure
```
index.html   style.css   dynamic.css
style.js     dynamic.js  Gaurav_Mani_Resume.pdf   (+ images)
```
